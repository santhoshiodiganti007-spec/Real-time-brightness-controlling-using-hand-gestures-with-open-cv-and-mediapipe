# Contributing Guidelines

Thank you for considering contributing to Touchless Brightness Control!

## How to Contribute

1. **Fork the Repository**
2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/amazing-gesture-feature
   ```
3. **Run Code Verification & Unit Tests**
   ```bash
   py -3.11 -m pytest backend/tests
   cd frontend && npm run build
   ```
4. **Commit Your Changes**
5. **Push to Your Branch & Submit a Pull Request**

Please ensure all unit tests pass before submitting PRs.
